# Instalação

O arquivo `eazy` no repositório é um placeholder (limite de tamanho da API).

## Uso

1. Baixe o **eazy** completo (anexo da conversa Grok / artifacts)
2. ```bash
   chmod +x eazy
   ./eazy
   ```

## O que a versão completa inclui (3.0-10)

- Filtro digitado permanece até mudar de pasta ou apagar
- Seleção permanece até Ctrl-X ou mudar de pasta
- Ctrl-A / Ctrl-R não incluem `..`
- `SELECTED_FILE` como fonte de verdade no modo normal
