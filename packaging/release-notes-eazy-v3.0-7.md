# eazy 3.0-7 (professional)

Esta versão move a seleção automática de duplicados de **F11** para **F12**.

O F11 fica livre para a função de tela cheia do terminal. No modo **Duplicados**, pressione **F12** para selecionar automaticamente um arquivo existente de cada grupo. A seleção continua pronta para Enter, Insert, apagar, copiar ou mover.

A seleção manual permanece em **Tab**, Espaço, Ctrl-A, Ctrl-X e Ctrl-R.

## Instalação ou atualização

```bash
curl -fLO https://github.com/vapesmadcat-blip/Easy_Player/releases/download/eazy-v3.0-7/eazy_3.0-7_all.deb
curl -fLO https://github.com/vapesmadcat-blip/Easy_Player/releases/download/eazy-v3.0-7/eazy_3.0-7_all.deb.sha256
sha256sum -c eazy_3.0-7_all.deb.sha256
sudo apt install ./eazy_3.0-7_all.deb
```
