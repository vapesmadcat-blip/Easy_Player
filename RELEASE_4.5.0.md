# Easy 4.5.0

Esta é a versão padrão recomendada do Easy, baseada no build revisado e testado enviado para esta release.

O pacote inclui:

- `eazy` 4.5.0 como executável padrão;
- `eazy-notes-editor` para edição de notas;
- `eazy-tor`, `eazy-ai.py`, launcher desktop e documentação.

## Instalação rápida

```bash
curl -fLO https://github.com/vapesmadcat-blip/Easy_Player/releases/download/eazy-v4.5.0/eazy_4.5.0_all.deb
sha256sum -c eazy_4.5.0_all.deb.sha256
sudo apt install ./eazy_4.5.0_all.deb
```

Ou use o instalador direto:

```bash
curl -fsSL https://raw.githubusercontent.com/vapesmadcat-blip/Easy_Player/main/install-from-web.sh | bash
```
