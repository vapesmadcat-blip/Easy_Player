# eazy 3.2.5 (release)
https://github.com/vapesmadcat-blip/Easy_Player

## 3.2.5
- F9 → Shell do sistema
- F9 → Ao sair: navegador ou anterior (EXIT_DIR_MODE)
- eazy --shell-init → função bash para cd ao sair

```bash
chmod +x eazy && ./eazy --install
eazy --shell-init >> ~/.bashrc && source ~/.bashrc
```
