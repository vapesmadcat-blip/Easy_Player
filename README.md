# eazy 3.2.6 (release)

https://github.com/vapesmadcat-blip/Easy_Player

## 3.2.6
- **PYTHON_CMD** (F9 → Configurar) — padrão `python3`
- **Enter** em `.py` → Executar / Ver / Editar
- **Ctrl-K** → Executar .py

## 3.2.5
- F9 Shell; EXIT_DIR_MODE; `eazy --shell-init`

## Instalação (zip em ~/prj, repo em ~/prj/Easy_Player)

```bash
cd ~/prj
unzip -o eazy-3.2.6-release.zip
cp -f eazy-3.2.6-release/* ~/prj/Easy_Player/
cd ~/prj/Easy_Player
chmod +x eazy install.sh eazy-notes-editor
./eazy --install
```
