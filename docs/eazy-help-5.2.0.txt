NAVEGAÇÃO, FILTROS E BUSCA
──────────────────────────
  Enter              Tocar item sob o cursor / entrar em pasta / abrir playlist
  Ctrl+Espaço / F6   Seleção inteira (Alt+Enter se o terminal permitir)
  Tab / Espaço       Marcar item; em pasta, soma recursiva aparece no indicador Dir
  Ctrl-A             Selecionar todos (fora de Duplicados)
  Ctrl-R             Inverter a seleção
  Ctrl-X             Limpar a seleção
  Ctrl-Backspace     Voltar ao último diretório
  Ctrl-H             Exportar HTML: seleção marcada ou lista da tela
  Ctrl-L             Ir à pasta do arquivo sob o cursor
  Ctrl-/             Ligar/desligar preview
  Ctrl-F             Busca recursiva (extensão, tamanho, texto)
  Esc                Sair da busca e voltar à pasta normal
  F1/F2/Ctrl-T       Ordenar tamanho/nome/data (pastas, histórico, playlists, filas)
  HD livre/total     Espaço livre / capacidade do filesystem da pasta atual
                     Ex.: /mnt/c/... consulta o mount de /mnt/c; /home usa o de /home
  F3                 Alternar visualização tela cheia/janela
  F4/F5/F6/F7        Filtrar áudio/vídeo/imagens/compactados
  F8                 Alternar entre filtro atual e TODOS
  Page Up/Down       Rolar a página
  Alt+0              Tela do terminal (log real por trás do fzf) + pausa
  Alt+Q              Pausar com read sem limpar a tela; Enter retorna

DUPLICADOS E PROGRESSO
──────────────────────
  Ctrl-D             Buscar duplicados ou reabrir a lista temporária
  F12                Amostra: um arquivo por grupo
  Ctrl-A             Marcar todos os duplicados
  Ctrl-T             Passar amostras (vermelho) para a seleção ativa
  Ctrl-R             Inverter a seleção ativa
  Ctrl-X             Limpar a seleção ativa
  Tab / Espaço       Alternar seleção do item focado
  Alt-X              Limpar a lista temporária de duplicados
  ● vermelho         Amostra fixa criada pelo F12
  ✓ amarelo          Seleção ativa (Enter, Del, copiar, mover)
  Progresso          Inventário, hashes e consolidação

FILAS, PLAYLISTS E AÇÕES
────────────────────────
  Insert             Enviar seleção para fila 1, 2 ou 3
  Ctrl-P             Alternar filas 1→2→3→diretório
  Ctrl-O             Abrir playlist .m3u/.pls
  Ctrl-G             Tocar histórico de arquivos tocados
  Ctrl-E             Shuffle / exportar
  Ctrl-K             Menu de ações (manutenção, converter, …)
  Ctrl-Y             Copiar seleção
  Ctrl-U             Mover seleção
  Ctrl-S             Salvar
  Ctrl-N             Notas rápidas (última nota / editor)

DOWNLOADS, TOR E TORRENTS
─────────────────────────
  Ctrl-B             Gerenciador de downloads (fila)
  Enter na fila      SEMPRE pergunta app + Tor (sugere o último usado)
  eazy-tor           Downloader de magnet/.torrent (incluso no .deb)
  Tor                Opção por item + torsocks (socks5://127.0.0.1:9050)
  F9 → Downloads     Motor padrão (aria/axel/wget/ytdlp) e parâmetros
  Destino            DOWNLOAD_DIR e TORRENT_DIR configuráveis

  CLI:
    eazy --torrent [opts] arquivo.torrent|magnet:...
    eazy-tor --dir ~/Downloads/Torrents --tor magnet:?xt=...

IA (eazy-ai) E NOTAS
────────────────────
  F9 → IA            Abrir chat com IA (eazy-ai.py)
  eazy-ai.py         Cliente de chat por API (incluso no .deb)
  Ctrl-N             Abrir última nota
  Editor de notas    Ctrl-N nova · Ctrl-S salva · Esc salva e sai
  Ctrl-E             Listar notas
  Del                Apagar nota
  Ctrl-R             Renomear
  Ctrl-X             Exportar para ~/Documentos/Easy-Notes/

  CLI:
    eazy-ai.py
    eazy-notes-editor

PLAYER, CONVERSÕES E PDF
────────────────────────
  Enter              Reproduzir (mpv / mplayer / vlc / ffplay)
  F9 → parâmetros    Editar o valor atual, substituir em campo vazio ou remover
  mpv: [d]           Marcar exclusão
  mpv: [D]           Marcar exclusão e ir ao próximo
  C (Ctrl-K)         Conversões: vídeo, imagem, PDF→HTML/texto/PNG, imagem→PDF
  PDF no Enter       Ler texto, converter HTML/PNG ou abrir no sistema

MANUTENÇÃO (Ctrl-K)
───────────────────
  S  Sistema         CPU, RAM, cache, processos, rede, logs
  H  HD              Disco, partições, SMART
  A  Som             Diagnóstico, reinício, teste de áudio
  V  Vídeo           GPU, codecs, otimização
  W  SWAP            Status, criação, limpeza
  Z  Vazios          Selecionar dirs vazios e arquivos regulares de 0 bytes
                     A raiz pesquisada fica protegida; dirs usam rmdir, sem recursão
  M  Menu completo   Manutenção
  Backup             Escolher o que salvar (.config, filas, hist…)
  Restaurar          Restaurar .tar.gz de backup
  V  Validar M3U     Limpar playlist
  P  Proteger        Pasta/arquivo com senha
  C  Conversões      Mídia e PDF
  DRY-RUN            Simula ações destrutivas (visível no header)
  sudo               Pede senha antes de comandos privilegiados

SISTEMA, CONFIG E SAÍDA
───────────────────────
  F9                 Configuração, overview de hardware, teste de som, IA
  F10                Este help (HTML / terminal / seções)
  Alt+0              Log do terminal (por trás do fzf)
  Alt+Q              Pausar com read sem limpar a tela; Enter retorna
  Ctrl-Q / Q / X     Salvar sessão e sair
  eazy -m            Manutenção / backup / restaurar
  Backup             eazy -m → Backup (escolhe o que salvar)
  Restaurar          eazy -m → Restaurar backup (.tar.gz)
  Temporários        ~/.config/eazy/tmp  (NÃO usa /tmp do sistema)
  Config             ~/.config/eazy/
  Backups            ~/.config/eazy/backups/

LINHA DE COMANDO
────────────────
  eazy [pasta|arquivo]
  eazy --verbose          Mostra o que está a processar
  eazy --ignore           Anónimo (sem persistências)
  eazy --unselect         Limpa seleção global/local e abre o eazy
  eazy --install          Instala deps + eazy + tor + IA + editor
  eazy --update-all       Atualiza todas as dependências do sistema
  eazy --shell-init       Função bash para cd ao sair
  eazy --torrent …        Encaminha ao eazy-tor
  eazy --update-ytdlp     Atualiza yt-dlp (binário oficial)
  eazy -h / --help        Ajuda curta
  eazy -V / --version     Versão

Pacote .deb inclui: eazy, eazy-index.py, eazy-convert-m3u.py, eazy-live-watch.py, full.c, eazy-tor, eazy-ai.py, eazy-notes-editor
